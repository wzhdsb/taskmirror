# 监控指标口径

数据零新增：全部由 `tasks` + `task_events` 派生（`GET /api/insights`，MCP `get_insights` 同源）。

| 指标 | 口径 |
|---|---|
| 执行者负载 | 非完成卡按 owner 聚合：执行中=在手，待验收=待验收数（待执行不计在办） |
| 停滞卡 | 执行中 且 `updated` 距今 > 4h（`updated` 由任何写入刷新，`add_log` 即心跳） |
| 验收滞留 | 待验收 且 `updated` 距今 > 24h |
| 逾期/临期 | `due` < 今天 / 0–3 天内，且未完成 |
| 阶段平均停留 | 相邻 status 事件时间差的均值（h）；当前进行中的一段不计 |
| 空列建议 | 待执行空且无停滞 → 建议拆新卡；忙闲差（某人在手≥3 且有人空）→ 建议派卡 |

时间戳兼容三种分辨率（`%Y-%m-%d %H:%M:%S` / `%H:%M` / `%Y-%m-%d`，迁移旧卡无秒）。

adviser 两层：规则层=本接口；LLM 层=主会话读 insights 后拆卡/验收（人最终把关）。
